# 地方政府與海外屬地職官表

地方官員職官表，編輯方式與內閣職官表一致。

## 開啟
https://annynn1990.github.io/wme-list/local-officials/

## 編輯方式
點擊頁面右上角齒輪，輸入管理密碼即可直接修改標題、分區、職銜、職等、定員及官員姓名。修改後按「儲存修改」即寫入 Cloudflare D1 雲端資料庫，無須修改 JSON 或重新部署。

## 專案檔案
- `index.html`：名冊與管理介面。
- `data.json`：原始名冊資料備份。
- 線上編輯內容儲存於 Cloudflare D1 的 `local-officials` 文件。
