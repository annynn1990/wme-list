# 地方政府與海外屬地職官表

黃名帝國地方政府及海外屬地職官名冊。

## 網頁

https://annynn1990.github.io/wme-list/local-officials/

## 資料檔

- `data.json`：地方政府分區及職官資料。
- `index.html`：自適應名冊頁面，支援搜尋。

## 更新資料

修改 `data.json` 中各分區的 `rows`：

- `title`：職銜
- `level`：職等
- `strength`：定員
- `name`：官員名稱

空白姓名會以「—」顯示；原始資料中的 `*` 會原樣保留。海外屬地資料目前尚未提供，因此先保留專區說明，不建立未經提供的官職。
